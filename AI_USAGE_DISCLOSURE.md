# AI Usage Disclosure

AI assistance was used during the development of this Customer Transactions API.

## Areas Where AI Assistance Was Used

AI assistance was used for:

- Understanding the requirements of the Customer Transactions exercise.
- Planning the Spring Boot project structure.
- Designing the Controller, Service, Repository, DTO, Entity, Enum, and Exception layers.
- Implementing and reviewing transaction-related Java code.
- Designing request validation rules.
- Designing transaction status transition rules.
- Implementing exception handling.
- Creating and reviewing automated tests.
- Troubleshooting compilation and test-related issues.
- Preparing project documentation and README content.
